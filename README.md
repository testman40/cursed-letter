## 制作資料と保存先

- `docs\00_基準資料` を作品制作の最上位基準資料置き場とする。
- `docs\00_基準資料` のファイルは原則として直接変更・削除・移動しない。
- Workによるプロット作成先は `docs\03_プロット` とする。
- 台本作成先は `docs\04_台本` とする。
- CSV化した台本の保存先は `data\scenario` とする。
- 素材対応表は `docs\05_素材対応表` で管理する。
- 公開・バックアップ関連は `release` で管理する。

## 基準資料

- `docs\00_基準資料` を制作上の最上位基準資料置き場とする。
- 基準資料は原則として直接変更・削除・移動しない。
- プロット作成時は基準資料を必ず参照する。
- 資料間に矛盾がある場合は作業を進めず報告する。
- Workによるプロット保存先は `docs\03_プロット` とする。
- 次工程は第一章「夏の山荘」の詳細プロット作成とする。
